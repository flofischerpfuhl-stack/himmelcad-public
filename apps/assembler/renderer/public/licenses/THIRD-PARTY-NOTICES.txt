How this library is used, and how to replace it
-----------------------------------------------

The OCCT/opencascade.js library is not linked into the application code.
It consists of exactly two files next to the application code:

  assets/replicad_single-<hash>.wasm   (WebAssembly module, unmodified from
                                        replicad-opencascadejs 1.1.0
                                        dist/replicad_single.wasm,
                                        SHA-256 4c9f22e9f3828dca6f3c95405934cdbe
                                        624e593c35266f47f392ab337478dbde)
  assets/replicad_single-<hash>.js     (its Emscripten loader, from
                                        dist/replicad_single.js, minified by
                                        the application build)

The WebAssembly module also contains the Emscripten 5.0.1 runtime and
system libraries it was compiled with (Emscripten: MIT or NCSA; musl libc:
MIT; LLVM libc++/libc++abi: Apache-2.0 WITH LLVM-exception).

Both files are loaded at runtime by the CAD-kernel Web Worker. You may modify
the library, rebuild it (the build configuration above plus the
opencascade.js Docker toolchain reproduce it), and replace these two files
with your build, keeping their file names. A replacement must export the
same bindings replicad uses. You may reverse-engineer the application to
the extent needed to debug such modifications. The corresponding source
code is available from the URLs above; Himmel:CAD makes no modifications to
it.
