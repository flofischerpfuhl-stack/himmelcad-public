Architect decision (P1/X6): snapshot markers are project bookkeeping, not scene entities — they never appear in the entity tree. They live in a "Snapshots" list reachable from File ▸ Recent's sibling menu "Snapshots ▾" (S-02 Menu: name, time, journal generation, "Restore…" action which is a journaled command with a confirmation Dialog naming the consequence) and through `snapshot.list/restore` rows. Automatic "Session start" markers: keep at most 5 (tunable) per project with FIFO retention; a session that makes no journal change creates none. User-named snapshots (Ctrl+S) are unlimited. Migration: existing projects with many "Session start" markers are compacted on next open under the same retention rule, one journaled command, reported in the console ("Compacted 41 session-start snapshots to 5").
