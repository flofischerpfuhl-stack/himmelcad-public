1. Zusammenfassung & Ziele

Dieses Dokument spezifiziert zwei zusammenhängende Builder-Capabilities, die heute nicht existieren: ein Spezifikationssystem (wie etwas gezeichnet/dargestellt/plotiert wird) und ein Plan-Tool (wie aus dem 3D/2.5D-Modell druckbare Planblätter entstehen). Beide sollen sich anfühlen wie CAD + PowerPoint: präzise, snappend, vorlagenbasiert — nicht wie ein reines Whiteboard.

Ziel 1 — Specs

Benannte, wiederverwendbare Darstellungs- und Plot-Regeln (Farbe, Strich, Stärke, Schraffur, Text, Dimension, Layer-Defaults). Bibliothek pro Projekt + User-Library. Popup-Verwaltung. Zuweisung an Entities/Layer. Dateiformat .hcspec / Library-Export.

Ziel 2 — Plan

Großes Task-Island: Blatt (Papier), CAD-Ausschnitt (Vektor + Raster), Rahmen, Stempel, Bemaßung, PDF-Export. Interaktion: Rahmen über Viewport ziehen, Snap an Blattkante; Stempel snappt an Rahmen. Inspiriert von Fernwork Canvas (Excalidraw-Shell) + PDF-Workbench.

Leitprinzip: Specs sind die gemeinsame Sprache. Pläne konsumieren Specs (Rahmenlinien, Stempel-Textstile, Plot-Strichstärken). Ohne Specs wird Plan-Tool zum One-off-Hack.

Non-Goals v1: Assembler-Mechanik, voller Civil-Alignment-Editor, Cloud-Library-Marketplace, echter 3D-to-2D-Section-Cutter (kann v2), Codex-Viewer-Fork (Plan nutzt Snapshots/API, ändert Render-Core nicht).

Begriff Definition

       ↓ (fehlt)
  ProjectDefaults
       ↓

4.3 Spec-Kategorien (v1)

Kategorie Felder
CurveSpec color, colorSource (override|byLayer|byBlock), lineTypeRef?, lineTypeScale, lineWeightMm, plotVisible

4.4 Benennung, Codes, Versionierung

  • id: stabil UUID / spec_… im Projekt
  • code: kurzer projektspezifischer Schlüssel (RK-BEST, max 32, unique in Library) — für Filter, Import-Mapping, Normen
  • name: menschenlesbar, mehrsprachig optional später
  • content_hash: bei jeder inhaltlichen Änderung neu (immutable object pattern)
  • revision: monotone Versionsnummer in der Library für Diff/UI
  • source: project | userLibrary | importedPack | dxfImport

Dateiformate:

  • .hcspec — einzelne Spec (JSON body, analog .hcalign)
  • .hcspecpack — Library-Export (mehrere Specs + embedded LineType/Hatch resources)
  • Im .hcad/.hcadx: unter objects/ content-addressed + Catalog-Index im Manifest-Abschnitt specCatalogHash

4.5 Commands (Core)

// Vorschlag Command-IDs
specs.library.ensureDefault
specs.upsert          { library: project|user, spec }
specs.delete          { specId }
specs.assignToEntities { entityIds[], specId }  // sets style_ref + optional attributes
specs.assignToLayer    { layerId, layerSpecId }
specs.resolvePreview   { entityId } → ResolvedStyle  // für UI-Vorschau
specs.importPack / exportPack

Alle schreibenden Operationen nur über Command-Journal (AGENTS.md). Keine UI-Mutation am Store.

4.6 Defaults & Bootstrap

Beim ersten Öffnen einer Spec-Library:

  • Built-in pack: Continuous, Dashed, Center, Hidden (klassische Linetypes)
  • Lineweights: 0.00 (default), 0.13, 0.18, 0.25, 0.35, 0.50, 0.70, 1.00 mm
  • Farbpalette: TrueColor + 8 neutrale CAD-Graus + Accent nur für Selection (nicht Spec-Default)
  • Optional: „Vermessung DE“ Starter-Pack (Bestand/Neu/Abbruch-Layer-Specs) — hinter Feature-Flag

4.7 Interaktion mit DXF-Import

  • Import erzeugt provisional Specs aus DXF Layer/Linetype-Namen (source=dxfImport)
  • User kann im Spec-Popup „Map to project Spec“ machen (RK → RK-BEST)
  • Kein stilles Überschreiben projektinterner Specs

5. Teil 2 — Plan Tool

5.1 Produktgefühl (CAD × PowerPoint)

CAD-Gefühl PowerPoint-Gefühl
Maßstab, Units, Snap, Ortho, echte Geometrie Folien = Sheets, Drag-Drop Stempel, Align-Guides
Layer-Sichtbarkeit im Viewport Vorlagen (Rahmen/Stempel) aus Bibliothek ziehen
Plot-Strichstärken / Mono Anfassen, verschieben, gruppieren, z-order
Viewport-Clip = Modellausschnitt „Slide master“ = Frame Template

5.2 Einstieg User

  1. Im Viewport gewünschten Ausschnitt wählen (Selection / View framed / active clip).
  2. Ribbon Output → Create Plan (oder Kontext „Create plan from view“).
  3. Task-Island öffnet sich (groß, nicht modal dimmend — DESIGN-SYSTEM: View darf bleiben, aber Fokus auf Island).
  4. Wizard-lite (eine Seite, keine Chat-Bubbles):
    • Papier: A4/A3/A1/A0, Hoch/Quer
    • Maßstab: 1:100 / 1:250 / 1:500 / custom
    • Plot profile: Farbe / Graustufen / Mono
    • Optional: Frame-Template vorwählen
  5. Sheet erscheint mit:
    • Papier-Rechteck
    • einem Model-Viewport (Inhalt aus Schritt 1)
    • leerem oder Template-Rahmen

5.4 Drei Inhalts-Schichten im Viewport

Schicht Inhalt Erzeugung
Vector model Curves, areas, points, text, dimensions, blocks Tessellation/Export aus Core in Sheet-Koordinaten (mm)
Raster underlay Point cloud, splats, heavy meshes, orthophoto Offline-Render-Snapshot (GPU/CPU) bei fester View-Matrix + DPI; gecacht per content hash
Sheet composition / chrome Rahmen, Stempel, freie Skizze, Notizen und Viewport-Platzhalter Excalidraw-Szene mit typisierten HimmelCAD-Metadaten

Viewport-Update: Wenn User den Viewport verschiebt/skaliert, invalidiert der Raster-Cache und wird asynchron neu gerendert (Progress in Status). Vektor-Layer live transformieren (billig).

5.5 Rahmen (Frame Templates)

  • Frame = Gruppe aus Linien/Polylines + optionalen Textfeldern (Attribute: Projektname, Datum, Maßstab, Bearbeiter, Blatt-Nr.)
  • Erstellung: im Plan-Editor „Create frame from selection“ oder dedizierter Frame-Editor (gleiche Island, Modus)
  • Gespeichert in User/Project Library als FrameTemplate (Vektor in Blatt-mm, Anchor-Punkte: corners, title-block region)
  • Snap: beim Platzieren magnetisch an Sheet-Edges und Margins (PowerPoint-Align + CAD-Snap)
  • Felder binden an Plan-Metadaten und Spec-Codes (Maßstab-Feld folgt Viewport)

5.6 Stempel

  • Typen: North arrow, Scale bar, Legend (auto from used Specs), Text stamp (ENTWURF), Company block, QR (optional later)
  • Snap an Frame-Anker („title-block-right“, „corner-bl“) und an andere Stempel
  • Fernwork-Pattern: Stamp library + place + flatten on PDF export

5.7 Interaktionsdetails (erwartet der User)

Aktion Verhalten
Viewport-Rechteck ziehen Definiert Clip im Modell; hält Aspect optional; zeigt Live-Maßstab
Doppelklick Viewport „Activate model space“ — pan/zoom im Modell, Rahmen dimmed (CAD paper/model toggle light)
Esc zurück Sheet-Edit / Tool abbrechen
Align-Guides beim Verschieben von Rahmen/Stempel: Mittel, Kanten, Abstände (PPT)
Ortho / Snap Toggle in Statusleiste der Island
Layer-Filter Viewport Checkbox-Liste; speichert pro Viewport
Export PDF Multi-Sheet; Vektor wo möglich; Raster eingebettet; Metadaten Titel/Autor
Save Plan im Projekt plans/ oder .hcplan Side-car; Command journal

5.8 Excalidraw-first mit klarer Autoritätsgrenze

Excalidraw verantwortet HimmelCAD verantwortet
Auswahl, Transform, Gruppen, Guides, Snapping, Zeichnen, Text, Bilder und responsive Canvas-Bedienung Blatt-mm, Papierformat, Multi-Sheet-Navigation und Persistenzschema
Rahmen, Planköpfe und Stempel als intuitiv editierbare Gruppen Typisierte Template-Metadaten, gebundene Felder und Bibliotheken
Interaktive Darstellung von Viewport-Platzhaltern Kanonische Modell-Geometrie, Georeferenzierung, ViewDescriptor und Maßstabsregeln
SVG/PNG-Erzeugung als Eingabe für Exporte Deterministische PDF/SVG/Bild-Komposition und Fidelity-Bericht

Entscheidung: Das PowerPoint-artige Bediengefühl wird nicht als eigenes Element- und Interaktionssystem nachgebaut. Eine dünne PlanDocument-Schicht ordnet pro Sheet eine Excalidraw-Szene und typisierte Metadaten zu. Physische Maße werden über eine explizite Sheet-Transformation abgeleitet; Excalidraw-Daten werden nicht zur Autorität für Projektkoordinaten oder CAD-Entities.

5.9 PDF-Pipeline

PlanDocument
  → for each Sheet:
       1. Create PDF page (pdf-lib) paper size
       2. Draw vector model layer (paths, text) in mm→pt
       3. Embed raster underlays (JPEG/PNG) with clip
       4. Draw frame + stamps (vector)
       5. Draw annotation layer (vectorize or embed SVG)
  → Write PDF bytes
  → Optional Electron save dialog / project artifact

Fidelity report:
  - vectorEntityCount, rasterTileCount
  - warnings: missing fonts, oversized raster, non-plot layers hidden

7. User Journeys (ausführlich)

J1 — Neue Spec anlegen und zuweisen

  1. User öffnet Specs-Island.
  2. „Neu → CurveSpec“, Code GEB-BEST, Name „Gebäude Bestand“, Linetype Continuous, Weight 0.35, Farbe grau.
  3. Speichern (Journal).
  4. Im Viewport Polylinien selektieren → Properties oder Specs-Island „Auf Auswahl anwenden“.
  5. Viewport zeigt neuen Stroke (RenderStyle aus Resolve).

J2 — DXF-Import mappt auf Specs

  1. Import DXF erzeugt provisional Specs/Layers.
  2. User öffnet Specs, filtert source=dxfImport, mapped „GEBAEUDE“ → GEB-BEST.
  3. Re-resolve; eine konsistente Projektnorm.

J3 — Lageplan 1:500 erzeugen

  1. User top-view, zoomt auf Grundstück, Create Plan.
  2. Wählt A3 quer, 1:500, Template „A3-Lageplan-QH“.
  3. Viewport füllt Zeichenbereich; Rahmen snapt an Ränder.
  4. Zieht Nordpfeil + Maßstabsbalken; Align an Rahmen-Anker.
  5. Legende generiert aus verwendeten Specs.
  6. Export PDF → Ablage im Projekt + optional OS-Dialog.

J4 — Rahmen-Template bauen

  1. Plan-Island → „Edit frames“.
  2. Zeichnet Linien (mit CurveSpecs!), platziert Textfelder mit Platzhaltern {{project.name}}, {{plan.scale}}.
  3. „Save as Frame Template“ → User library.
  4. Nächster Plan: Template aus Library droppen → snapt.

J5 — Punktwolke im Plan

  1. Viewport enthält PointCloud + Grenzen (Kurven).
  2. Plan: Kurven = Vektor, Cloud = Raster-Tile bei 150–300 dpi.
  3. User ändert Maßstab 1:500→1:250 → Raster-Regen (Progress), Vektor scharf bleibt.

10. UI-Vertrag (DESIGN-SYSTEM)

  • Task-Islands: nicht modal (kein Dimmer), drag handle, Display-Titel wie ImportChat header metrics wenn Insel-Chrome, Function-Panel-Dichte für kleine Forms
  • Keine Chat-Bubbles, keine Wizard-Novel
  • Controls: shared Select, Checkbox; Höhe --hc-size-control-h
  • Eine UI-Schriftgröße-Familie (11/10); Mono nur Codes/Hashes
  • Primary button = neutral press, nicht Accent-Wash
  • Console: Start/Ende/Dauer jeder Export- und Snapshot-OP; progressKey bei >1s
  • Ribbon EN labels (product English UI check)
