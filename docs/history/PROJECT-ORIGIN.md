# Project origin

Status: historical context only. Current product names, priorities, and
architecture are defined by the normative documentation.

Himmel:CAD began as a proposal for a commercially distributed, source-available
civil CAD platform designed around large 3D point clouds from its first
architecture. The initial concept required a secure Electron application,
streamed spatial data, reusable rendering, custom dark UI, command-based
editing, undo/redo, and a project format suitable for future products.

The original family concept contained a primary CAD product, a photogrammetry
product, and a browser viewer. Names, engines, licensing assumptions, and
implementation priorities evolved through later owner decisions and accepted
ADRs. In particular, the current product identity and sequencing must not be
inferred from this origin summary.
