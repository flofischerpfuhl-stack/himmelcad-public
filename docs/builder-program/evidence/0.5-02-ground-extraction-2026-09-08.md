# 0.5-02 ground extraction — evidence

Date: 2026-09-08  
Owner: `pointcloud`  
Algorithm: `hcad.pointcloud.ground-progressive@1`

## Outcome

Builder now exposes **Pointcloud → Extract ground** for one selected, visible point cloud. The command opens the detachable right-hand **Extract ground** function panel, captures the P4 visible class set and active viewing box, previews a bounded coarse-LOD classification in the viewport, and runs extraction as an S-05 cancellable job with grid, filter, classify, and bake phases.

One successful extraction publishes one canonical journal transaction containing both effects: the source cloud advances to an edited revision with accepted points assigned LAS class 2, and a derived `PointCloud` named from the requested output is created as a baked, native Potree dataset. The derived entity records the exact source id, source revision, source content hash, source placement revision, SMRF parameters, captured scope, immutable algorithm id, and the `outdoor_ground_source`/`ground_cloud` source roles. It is explicitly a point cloud, not an inferred DGM; its sealed `hcad.mesh-source-roles@1` admission makes it selectable by the Pointcloud-to-Mesh hand-off.

## Implementation surfaces

- `crates/himmelcad-sidecar/src/ground_classification.rs`: additive shared SMRF core/result refactor. PhotoLab's existing `classify_ground` entry point remains a thin wrapper over the same deterministic core.
- `crates/himmelcad-sidecar/src/pointcloud_ground.rs`: streamed Potree hierarchy traversal, P4 scope filtering, deterministic classification membership, residual statistics, source class rewrite, ground-only bake, and bounded coarse preview.
- `crates/himmelcad-sidecar/src/canonical_app_runtime.rs` and `canonical_project_store.rs`: exact source capture and CAS revalidation, content-addressed publication, recipe/source-role construction, and journal-last atomic publication with cancellation.
- `crates/himmelcad-sidecar/src/main.rs`: typed preview/extract/cancel RPCs, operation registry, scratch cleanup, S-05 progress, and cancellation routing.
- `apps/builder/renderer/src/GroundExtractionPanel.tsx`, `GroundPreviewOverlay.tsx`, `App.tsx`, `project.ts`, and `ribbon.ts`: visible ribbon/context-menu entry, detachable function panel, presets and typed inputs, live success-tone overlay, typed result/console summary, job lifecycle, undo-aware reload, and Mesh hand-off.
- `schemas/automation/himmelcad-automation-v1.schema.json`, generated command artifacts, and `docs/builder-program/REGISTRY.md`: S-01/P11 rows `pointcloud.ground.extract`, `pointcloud.ground.preview`, and `pointcloud.ground.cancel`, all under `owner: pointcloud`.
- `sdk/python/src/himmelcad/models.py` and `sdk/python/tests/test_sdk.py`: generated, field-level request/preview/result models preserve parameters, source revision, class/extract counts, residual statistics, deterministic hash, point-cloud-not-DGM identity, and Mesh source role instead of collapsing the operation payloads to opaque mappings.
- `packages/@himmelcad/ui/gallery/Gallery.tsx`: serially regenerated **Extract ground panel** gallery section in idle, running, and done states.
- `scripts/perf/viewer-baseline.mjs`: additive `--metadata-url` staging override so the existing V-02 frontier-only harness can inspect a prepared dataset when attached to a Vite Preview host as well as Vite's development `/@fs` route.

## Accuracy-fixture note

The supplied 104 M-point prepared dataset does not include a reviewed label manifest. Consequently this evidence does not manufacture reference truth or report precision/recall for that dataset. The deterministic small outdoor fixture carries the work-package floor assertions; the large dataset proves the separate operational gates (complete extraction, native bake, phase cancellation, and bounded memory). A future reviewed label sidecar can be evaluated by the same versioned algorithm without changing the recipe or output contract.
