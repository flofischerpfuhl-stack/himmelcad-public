# 0.5-08 measurement basics — evidence

Date: 2026-09-08  
Owner: `measure-inspect`  
Profile: `hcad.measurement@1` (`point`, `distance`, `heightDifference`)

## Outcome

Builder now exposes **Inspect → Measure point / distance / height difference** and a saved-measurement list. An armed measurement tool owns its S-03 gesture rows, consumes exact winners from the existing viewer snap pipeline, exposes S-04 candidate cycling, and accepts S-10 typed X/Y/Z coordinates as fixed anchors. Pointer previews remain view-local. A terminal accepted anchor creates one canonical `hcad.measurement@1` entity through one queued journal transaction; deletion is also a canonical transaction with exact revision CAS.

The project tree projects saved measurements below a virtual **Measurements** group. The docked panel lists and deletes them, and selection opens Properties with the stored metric and every exact anchor. UI, console, and automation share the generated P11 rows `measure.point`, `measure.distance`, `measure.dz`, `measurement.list`, and `measurement.delete` and use the S-01 admission envelope.

## Precision and project-unit note

The current Builder project profile exposes metres in its status/settings surface and S-01 does not yet carry per-coordinate source decimal metadata. This slice therefore consumes the current metre setting and applies the shared six-decimal project ceiling, additionally bounded by zoom and the formatter's explicit anchor-precision argument. The formatter and tests already accept other project units and stricter anchor caps without changing measurement truth.

No render-crate files were changed. Edits in the shared Builder host are limited to measurement integration seams (snap-address projection and the construction-tool LMB callback); concurrent viewing-box, ground-extraction, menu, and snapshot behavior was not changed to resolve its independent verification failures.
