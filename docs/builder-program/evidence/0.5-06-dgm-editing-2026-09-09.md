## Delivered surface

- Mesh **Edit surface…** opens a docked function panel for exactly one selected `Surface` or `DigitalElevationModel`. Context-menu activation binds the contextual selection before opening the panel.
- The panel selects a project-XY region from the reused 0.5-02a polygon/rectangle fence or a closed Draw boundary polyline. Fence points and boundary vertices remain authoritative; no Z or CRS value is synthesized. The viewport shows the region at 8% accent alpha.
- Smoothing supports Gaussian and median height filters with a metre radius. It cuts only source triangles whose three vertices lie in the polygon, preserves boundary-crossing triangles byte-for-byte, protects TIN boundaries and authored constrained edges, and refills the patch through deterministic constrained Delaunay triangulation. Protected vertices are never moved.
- Downsampling deterministically retains constraints and terrain extrema, proposes a thinned constrained patch, and computes the maximum vertical difference on the complete source/candidate piecewise-linear overlay: source vertices, candidate vertices, and every source/candidate edge intersection. A proposal over target is rejected in favor of the exact source mesh; the target is never relaxed.
- The typed result contains before/after active vertex and triangle counts, affected triangle count, region area, maximum/RMS vertical error, target/certified state, outside-region identity hash, and result hash. The panel and Builder console use the same result.
- Preview returns a bounded V-05 overlay of at most 20,000 triangles at 50% alpha and draws protected constraints in support blue. The bake recomputes from the exact source revision and rejects a hash mismatch against a same-parameter preview.
- Preview and bake run through the shared cancellable operation registry with phase/progress emission. Region, preview algorithm, parameters, and result hash are atomically checkpointed under project staging. Cancellation is checked during filtering, overlay certification, prepared-mesh construction, and before journal publication.
- Apply builds the prepared triangle-mesh dataset before one journal-last staged import. It creates a new immutable elevation-surface entity with `hcad.derived-recipe@1`, exact source id/revision/content hash, region and operation parameters, algorithm identity, result metadata, and `hcad.derived-from@1`; the source generation is not mutated. Canonical undo of the create removes the derived generation and therefore exposes the exact source again.
- P11 rows `mesh.edit.region.select`, `mesh.edit.smooth`, and `mesh.edit.downsample` use the S-01 envelope, Builder product scope, canonical command generation, and `owner: mesh-terrain`. The renderer automation dispatcher accepts typed project-XY polygons as `[x, y]` tuples or `{x, y}` values and routes to the same project-session/sidecar methods as the UI.
- The shared gallery contains **Edit surface panel** states for region selected, smooth preview, and downsample result in light and dark themes.
