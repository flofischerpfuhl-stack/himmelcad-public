# 0.5-03 spatial sampling and mean-height rasterize — evidence

Date: 2026-09-08  
Owners: `pointcloud`; `mesh-terrain` for the prepared `grid_source` role  
Algorithms: `hcad.pointcloud.sample@1`, `hcad.pointcloud.rasterize-height@1`

## Outcome

Builder exposes **Pointcloud → Sample** and **Pointcloud → Rasterize mean height** from the ribbon, the selected-cloud context surface, the console, and automation. Both commands open the shared docked/detachable function-panel pattern and run as cancellable S-05 jobs over a captured P4 scope: the exact source revision, effective Reference/Editable visibility, visible classification codes, source placement, and active viewing box.

Sampling creates a new immutable, native Potree point-cloud dataset. The source cloud is never rewritten. The modes are:

- **Distance:** visit stable source point ids in ascending order and retain the first point whose project-space 3D distance from all already retained neighboring-cell points is at least the requested spacing.
- **Grid:** for each project-XY cell, compute finite mean Z, then choose the existing source point with minimum `abs(z - mean_z)`; ties use XY distance to the cell center and then stable source point id.
- **Random:** compare the SHA-256 draw of fixed recipe seed `0x4843414450380001` plus stable source point id with the requested percentage threshold. Traversal arrival does not affect selection.

Rasterize makes one prepared `hcad.pointcloud.height-grid@1` dataset using project-XY cell centers and mean/min/max/count aggregation. Records preserve validity, value, admitted point count, and variance. NoData remains invalid; an explicit finite fill policy writes a valid caller-selected value. Mean/min/max products are canonical `hcad.elevation-surface@1` entities with a sealed `hcad.mesh-source-roles@1` source role of `grid_source`; count is a density `hcad.raster-image@1` and deliberately has no Mesh height-source role.

Both outputs carry `hcad.derived-recipe@1`, exact source id/revision/content hash/placement revision, parameters, P4 scope, deterministic rule/seed, output hash, a `derivedFrom` relation, and a content-addressed prepared dataset. Source CAS is rechecked immediately before publication. Publication stages immutable content and appends one journal-last create transaction; document undo removes only the derived entity and leaves the source unchanged.

## Lifecycle and concurrency

- Scan/select-or-aggregate/bake progress maps into the main-process S-05 registry. Cancellation is checked at every bounded source node, between passes, every 65,536 raster cells, and during generic prepared-dataset staging.
- Each operation has its own cancellation token and scratch root. Read-only sampling/raster jobs may scan concurrently. Canonical publication is serialized through the runtime mutex, and a source revision/placement mismatch rejects late publication.
- A cancelled prepare never calls publication. Per-operation scratch is removed on scope exit, and the generic cancellable publisher is journal-last, so no partial canonical entity is reachable.
- Distance/grid working sets reject above 10 million entries. Raster grids reject above 50 million cells before allocation. Potree input is read one bounded node at a time; raster memory scales with output cells rather than source points.

## Authority and follow-up notes

- The accepted ADR 0031 item 6 prose predates this work package and still enumerates release-0.5 recipe producers without naming `hcad.pointcloud.sample@1` or `hcad.pointcloud.rasterize-height@1`. This explicit owner work package requires both P10 recipes, so the narrow runtime admission includes them. The architect should reconcile the accepted record through an additive/superseding ADR rather than silently rewriting ADR 0031 history.
- A separate physical small-LAS import/conversion was not rerun. The small exact-cell prepared fixture carries fixed deterministic hashes, while determinism was additionally proven by two full passes over the prepared 103.7 M-point LAS source.
- Mesh 0.5-05 is not implemented in this slice. This package publishes its exact canonical `ElevationSurfaceGeometry::Grid`, prepared format id, immutable source-role resource, mapping, and hashes for that consumer.
- No Windows-only packaging or class-D GPU timing was required. The V-02 check is deliberately non-timed and ran on the available Linux Quadro M2200 WebGL2 lane.
