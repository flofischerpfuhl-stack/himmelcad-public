## Module dependency result

Today's tree passes with the exact shrinking allowlist:

```text
module dependencies: ok (7 Rust crates, 11 Rust edges, 13 TypeScript packages, 65 TypeScript edges, 8 allowlisted exceptions, 1.82s)
```

The checker runs `cargo metadata --format-version 1 --no-deps`, rejects every
workspace crate or scoped app/package missing from the layer map, and checks
only workspace-to-workspace edges. The TypeScript side walks every source file
below `packages/@himmelcad/*` and `apps/*`, parses static imports, exports,
`require()` and literal dynamic `import()` with the repository's TypeScript
compiler API, resolves relative cross-package and configured subpath edges,
checks all dependency sections in every package manifest, and rejects
undeclared workspace imports.

Allowlist size by ecosystem and layer pair:

| Ecosystem  | Layer pair              | Count | Exact edges                                                            |
| ---------- | ----------------------- | ----: | ---------------------------------------------------------------------- |
| Rust       | foundation → display    |     1 | `himmelcad-io → himmelcad-render`                                      |
| Rust       | command → display       |     1 | `himmelcad-sidecar → himmelcad-render`                                 |
| Rust       | display → foundation    |     2 | `himmelcad-render → himmelcad-core`; `himmelcad-wasm → himmelcad-core` |
| Rust       | foundation → foundation |     1 | `himmelcad-io → himmelcad-core`                                        |
| Rust       | command → foundation    |     1 | `himmelcad-sidecar → himmelcad-core`                                   |
| TypeScript | command → interface     |     1 | `@himmelcad/automation-host:. → @himmelcad/agent:.`                    |
| TypeScript | display → display       |     1 | `@himmelcad/viewer:. → @himmelcad/viewer:legacy`                       |

The same exact edges are architectural violations in the layer-map
configuration, independently of the allowlist. Removing an allowlist row while
the edge remains therefore fails; leaving a row after the edge disappears also
fails. There are no wildcard or transitive entries.

The four negative fixtures passed and prove rejection of an upward edge, a
domain-to-domain edge, an undeclared workspace import, and a stale allowlist
entry.
