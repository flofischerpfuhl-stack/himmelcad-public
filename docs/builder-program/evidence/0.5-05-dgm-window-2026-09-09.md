## Delivered surface

- The Mesh ribbon exposes **Create surface** and opens a detachable, resizable 720 × 560 px DGM task island. The viewport remains interactive.
- The three-column window contains selected source rows, counts, glyphs and role Selects; rule inputs with metre units; automatic-boundary, boundary-exclusion and 2D-crop controls; a checked error list; per-error Drop/Snap/Split/Exclude actions; and the required Check/Create surface/Cancel footer.
- Point clouds capture the P4-visible classification set at Check time. Points and grid sources are admitted as points. Existing authored `Polyline3D` entities are consumed as Breakline, Boundary, Form line or Exclusion sources without changing Draw implementation files.
- Draft capture freezes exact entity id, revision, version hash and placement. Point-cloud input is streamed node-by-node and thinned to an existing authoritative point nearest each XY-cell mean height. The bounded cell map rejects more than 10 million retained cells. Mean-height grids retain their stored cell-centre XYZ values.
- Check reports heightless/non-finite vertices, duplicate XY, conflicting duplicate heights, zero-length edges, breakline vertices off the admitted point set, crossing breaklines, boundary defects, vertices outside the boundary and too few points. Fixes mutate only the checkpointed draft and return exact resolved/introduced error-id sets.
- Creation uses a constrained Delaunay TIN, preserves boundary/breakline constraints, applies holes, the breakline-exclusion union, long-edge automatic-boundary rejection and a 2D crop polygon. No missing Z is synthesized.
- Publish builds the existing V-02 prepared triangle-mesh dataset first, seals `hcad.mesh-source-roles@1`, records a `hcad.derived-recipe@1` P10 recipe, and submits the new elevation-surface entity in one canonical staged-import journal transaction. The typed result reports entity/dataset identity, triangles, projected area, Z range, source residual and journal entry.
- Draft checkpoints are atomically renamed under project staging. Cancelled or failed work reaches no canonical publish. Reopening the same draft id reads the checkpoint; prepared output is outside the checkpoint and is not treated as published state.
- P11 rows `mesh.surface.draft.create`, `mesh.surface.check`, `mesh.surface.draft.apply_fix`, and `mesh.surface.create` are generated for Builder with owner `mesh-terrain`. Builder UI automation dispatch calls the same project-session methods as the visible window.
- `spade` 2.15.0 is exact-pinned for constrained Delaunay construction. Its MIT/Apache-2.0 license and the newly selected transitive license rows are recorded in `LICENSES/THIRD_PARTY.md`.
