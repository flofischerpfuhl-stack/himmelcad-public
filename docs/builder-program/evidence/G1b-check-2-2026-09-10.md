# G1b-check-2 — Builder picks, snaps, and renders against the PhotoLab G1c oracle

Date: 2026-09-10  
Builder HEAD: `909e0e5`  
Result: **FAIL**

The sparse cloud renders, but only three of its seven requested Line-tool
cloud-point snaps agree with the PhotoLab oracle. Four resolve to a different
point outside the oracle's mean-nearest-neighbour tolerance. The dense import
was not attempted because the literal `free` memory figure was below the
package's 8 GB safety gate. Both requested republished DEM packages report a
successful UI import, then fail viewer residency: Frame All is blank and no
surface elevation is available at any of the seven expected-valid oracle XYs.

The four corner-interior probes are empty for both DEMs, and the DTM centre is
also empty, as PhotoLab's addendum predicts. Those observations do not establish
correct hole masking because the entire DEM is absent; notably, the valid DSM
centre and all fourteen dense-point rows are empty too.

No product source or fixture was changed. Builder wrote only the fresh project,
profile, screenshots, and logs under `.build/g1b-check-2/`. No commit was made.

## Method and safety gate

All executed imports used the visible route **File → Import… options → PhotoLab
product dataset → Choose… → native directory chooser → Import** on `DISPLAY=:0`.
The Builder UI was driven through its Electron CDP endpoint as specified by
V-01b; X11 keystrokes operated the native chooser. Draw → Line supplied the
point/surface probe and its visible `Snap:` state. No preload API, sidecar import
RPC, renderer pick API, package decoder, or direct grid query was used to obtain
Builder results.

The in-app Browser skill was inspected first, but its browser list was empty, so
the documented Electron-CDP fallback was used. The project is
`.build/g1b-check-2/profile/canonical-projects/builder-default.hcad`.

## Findings and verification limits

1. Sparse cloud snapping is not oracle-stable at four of seven deterministic
   points. Exact mismatches are recorded above; the largest is 3.276318 m.
2. Both republished DEMs pass the chooser/import job but fail the Builder viewer
   residency contract with the same visible error. They render no geometry and
   provide no surface pick or snap at expected-valid cells.
3. Dense was intentionally not loaded under the explicit memory gate, so its
   three cells remain unverified rather than being converted into product
   failures.
4. The DEM corner/centre observations follow the PhotoLab addendum and do not
   reinterpret the validity bitset. No direct package or grid read was used as a
   substitute for Builder UI behavior.

No source-level test suite was run because this package changes no product code.
Visual inspection covered all produced screenshots, the pick JSON files were
checked against `hcad.photolab-g1c-oracle@1`, and `git diff --check` was run after
the documentation edits.
