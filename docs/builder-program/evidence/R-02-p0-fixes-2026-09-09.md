# R-02 — P0 fixes from the R-01 demanding-user review — 2026-09-09

## Result

The three R-01 code defects were reproduced and repaired. General file import is
again the primary File ribbon action, native drag-and-drop reaches that same
workflow, project replacement no longer disposes a viewer underneath live
overlay effects, and `default-layer` is now independent system bootstrap state
rather than part of the first undoable drawing transaction.

R-02 is **implemented but the release gate is not fully green**. The visible
development build passed the three P0 workflows. The requested packaged road
scan appearance run could not start because the package command stopped at the
pre-package automation integrity check with `automation schema hash mismatch`.
The release Rust, WASM, renderer and Electron builds had completed before that
check. No package artifact was produced, so this report does not relabel the
development run as a packaged run and does not claim that the 103.7 M-point
entity appeared in a package.
