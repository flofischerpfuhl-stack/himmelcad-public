# V-01 measurement-authority evidence — 2026-09-04

## Outcome

V-01 implements the VC-D1 measurement authority and its callable query seam.
The fixed 2,048-frame ring correlates a successful surface-present completion
with input, CPU phases, asynchronous GPU sequence, exact logical primitive and
draw counts, policy/budget reasons, streaming debt, residency and freshness.
The snapshot and private sampling query return immutable data from that same
ring. The HUD surface remains assigned to S-08, as permitted by the V-01 slice.

The declared present source is `raf-render-complete`. The rAF timestamp records
when browser scheduling began; the authoritative record is appended only after
the renderer reports `Presented` and the host call completes. This is neither
rAF interval alone nor an OS compositor/display timestamp. No displayed-frame
timestamp API is available in this path, so the distinction remains explicit
in every sample and baseline artifact.
