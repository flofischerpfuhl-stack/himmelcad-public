# 0.5-04 — Draw line/polyline evidence (2026-09-09)

## Outcome

The Builder now exposes **Draw → Line / Polyline / Boundary polygon** through the generated command registry and the S-03 gesture arbiter. The three tools share S-10's construction bar and one `DrawToolController`; accepted pointer, constrained, and absolute-coordinate input converges on the same vertex type and canonical write path.

The landed subset includes:

- exact point/cloud-point, endpoint, midpoint, intersection, and perpendicular candidate handling; Up/Down uses S-03's live-candidate gate and Tab is reserved for construction fields;
- 45° direction snapping, typed length, absolute Z, ΔZ, and slope %, including `ZeroRunForSlope` refusal;
- renderer-native accent preview, 6 px pending-vertex square, support-blue defining geometry, and the existing selected-polyline direction payload;
- per-vertex `hcad.component.point-acquisition@1` records, including exact source id/revision/provider/primitive for picks and explicit typed/constrained modes;
- plain/breakline/boundary roles. Breakline and closed boundary payloads carry the matching Mesh source-role spelling without editing the concurrent Mesh domain;
- one canonical transaction for creation at the second vertex and one transaction for each subsequent vertex/closure. Vertex Undo compensates the newest root command before the creation command; explicit panel Cancel compensates the whole in-progress chain;
- canonical list/reopen support and compensating undo/redo primitives in the sidecar;
- typed vertex-list automation for `draw.line`, `draw.polyline`, and `draw.boundary`, plus active-tool `draw.vertex.add/constrain/type/undo` commands using the S-01 envelope;
- Draw-panel gallery states for idle, live drawing, and closed boundary in both themes.
