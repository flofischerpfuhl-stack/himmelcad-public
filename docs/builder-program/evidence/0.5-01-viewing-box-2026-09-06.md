## Outcome

Builder exposes the complete Viewing Box workflow through **View → Viewing Box** and its function panel. A user can create a canonical named box from the current selection, six typed Min/Max extents, a viewport click, or a viewport box drag; edit it with six face grips, eight corner grips, rotation rings, or typed extents; choose **Keep inside** or **Remove inside**; activate, rename, list, unlock, or remove saved boxes; and close the panel without losing the active clip. A named viewport chip reopens the panel while grips are disarmed.

Lock is a registered cancellable S-05 job. It filters the kept region from each resident Potree source into a real prepared hierarchy, publishes the completed artifacts atomically, and swaps the full point sources for reduced proxies that enter the native frontier. The renderer's shared clip planes remain active so mesh/CAD and other mixed-scene content keeps the same box semantics; the cost of retaining those planes is therefore part of the still-open VB-D8 measurement below. Cancellation and publication failure keep the prior scene intact, unload provisional proxies, and revoke all newly staged datasets. A majority-result Remove-inside lock uses VB-D12 edit-freeze rather than baking nearly the whole cloud. Unlock restores source visibility while retaining the revision-keyed cache for reuse.

Every placed box is immediately stored as a canonical entity. Grip previews and typed drafts are view-local; pointer-up or an accepted field edit enters the single canonical commit path. The box name, center, exact half-extents, quaternion, operation, lock state, bake identity, and prepared frontier references survive flush/close/reopen. A persisted bake is restored only when its cache identity still matches current source entity, placement, and dataset revisions. A later settled project snapshot with a changed point-source entity revision or placement now schedules a coalesced rebuild; completed replacement proxies become visible atomically, while cancellation or failure retains the previous locked bake.
