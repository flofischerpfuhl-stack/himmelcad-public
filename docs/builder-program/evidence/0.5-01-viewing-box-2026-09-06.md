Date: 2026-09-08  
Owner: `view` / S-09  
Profile: canonical `hcad.viewing-box@1`, ViewState v2 entity-referenced clips

## Outcome

Builder exposes the complete Viewing Box workflow through **View → Viewing Box** and its function panel. A user can create a canonical named box from the current selection, six typed Min/Max extents, a viewport click, or a viewport box drag; edit it with six face grips, eight corner grips, rotation rings, or typed extents; choose **Keep inside** or **Remove inside**; activate, rename, list, unlock, or remove saved boxes; and close the panel without losing the active clip. A named viewport chip reopens the panel while grips are disarmed.

Lock is a registered cancellable S-05 job. It filters the kept region from each resident Potree source into a real prepared hierarchy, publishes the completed artifacts atomically, and swaps only the point pass to the reduced native frontier. Mesh/CAD and other passes keep the six clip planes. Cancellation and publication failure unload provisional proxies and revoke all staged datasets. A majority-result Remove-inside lock uses VB-D12 edit-freeze rather than baking nearly the whole cloud. Unlock restores source visibility while retaining the revision-keyed cache for reuse.

Every placed box is immediately stored as a canonical entity. Grip previews and typed drafts are view-local; pointer-up or an accepted field edit produces one S-07 journal transaction. The box name, center, exact half-extents, quaternion, operation, lock state, bake identity, and prepared frontier references survive flush/close/reopen. A persisted bake is restored only when its cache identity still matches current source entity, placement, and dataset revisions; otherwise lock rebuilds it.

## Concurrency and change-surface notes

The implementation consumes the landed S-03 arbiter, S-04 selection, S-05 job registry, S-07 journal, S-08 ViewState v2, V-02 frontier, and S-10 typed controls. It does not modify the S-10 construction bar/tree ownership or the protected V-03 scheduler/governor. Builder, shared UI, viewer kernel, canonical sidecar, Electron bridge, automation schema/generated tables/Python SDK, gallery, benchmark, and tests were traced together.

Subjective drag feel beyond the numeric cadence and grip-error gates remains a human judgment. Renderer-native point picking already resolves baked proxy addresses back to their full-precision source entity; broader end-to-end snap workflows over every supported point-cloud encoding remain outside this focused gate.
