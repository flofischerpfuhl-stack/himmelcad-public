# Himmel:CAD website v2 — final report

Status: implementation complete in the `website/v4` worktree. No deployment or push was performed.

## Pages built

- `/` — family overview, status, products, licence essentials and next routes
- `/photolab/` — workflow, products, run lifecycle, evidence and release readiness
- `/builder/` — current build, verified inventory totals, active programme and planned outcomes
- `/cap-weltview/` — companion products and current boundaries
- `/roadmap/` — R1–R4 outcome stages without release dates
- `/pricing/` — free tier and commercial licences on request (no prices set)
- `/licence/` — plain-language BSL 1.1 + Additional Use Grant summary
- `/download/` — manifest-driven downloads with an honest empty state
- `/legal/` — English legal notice (Impressum)
- `/privacy/` — English privacy information including service-worker Cache Storage
- `/offline/` and `/404.html`

The site is generated by a Node 22 built-ins-only script. It includes clean URLs, shared navigation and footer, fingerprinted assets, responsive local hero formats, a manifest, raster and vector icons, a versioned service worker, offline fallback, redirects, CSP/security headers, JSON-LD data files, social metadata, sitemap/robots output, print styles and the empty-release workflow.
