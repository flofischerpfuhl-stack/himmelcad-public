## Adding media

1. Put the named file in `website/src/media/`. For a screenshot, an optional WebP with the same basename will be preferred when present while the PNG remains the fallback.
2. Keep its dimensions and description aligned with `website/content/media.json`.
3. Run `node website/build.mjs`. The warning for that slot disappears and the figure is rendered automatically.
4. Run `node website/check.mjs` and inspect both generated screenshots for the affected page.
